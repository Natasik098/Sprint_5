# Sprint_5 - Автоматизация тестирования Stellar Burgers

## О проекте 
Проект выполнен в рамках обучения на курсе Яндекс Практикума.
В проекте реализованы автотетсты регистрации, авторизации, работы с личным кабинетом и переходов в разделы конструктора.

## Используемые технологии:
- Python
- pytest
- Selenium WebDriver
- Google Chrome
- Faker

## Покрытые сценарии 

### Регистрация

- Успешная регистрация с валидными данными пользователя
- Ошибка регистрации при пароле короче 6 символов

### Вход в аккаунт

- вход по кнопке «Войти в аккаунт» на главной
- вход через кнопку «Личный кабинет»
- вход через кнопку в форме регистрации
- вход через кнопку в форме восстановления пароля

### Навигация в Личном кабинете

-  переход по клику на «Личный кабинет»
- переход из личного кабинета в конструктор 
- переход по клику на «Конструктор» и на логотип Stellar Burgers
- выход по кнопке «Выйти» в личном кабинете

### Конструктор

- переход к разделу «Булки»
- переход к разделу «Соусы»
- переход к разделу «Начинки»

## Установка зависимостей:

pip install -r requirements.txt

# Запуск всех тестов:
pytest tests -v
